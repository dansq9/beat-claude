Onboarding V1 wireflow

Product Designer 005, brief version 2026-07. Low-fidelity on purpose. Every screen links its decision to session IDs from the fixture. Use the tabs, or the buttons inside each screen.

Old flow: Account → Invite 3+ (blocking) → Integrations wall → Project → Tutorial.
New flow: Account → Pick a template → Live sample project (first value) → contextual invite → one recommended integration. The setup checklist carries anything that was skipped.
